# GrowthLens

영상 기반 영유아 발달 관찰 기록 및 진료 연계 웹 데모

보호자가 집에서 남긴 관찰을 정량 지표로 바꾸어, 의사의 판단 근거로 전달합니다.

## 개요

- **대상**: 14~15개월 영유아의 보호자
- **측정 영역**: 대근육운동 · 소근육운동 · 사회성 (MVP 범위)
- **플랫폼**: 웹 (클라이언트 전용, 백엔드 서버 없음)
- **현재 단계**: 로컬 데모 (배포 없음)

보호자가 앱의 안내에 따라 아이의 행동(서기, 블록 쌓기, 호명 반응)을 촬영하면,
브라우저에서 바로 분석해 정량 지표로 보여주고 기록합니다.

## 기술 스택

- **Frontend**: React
- **영상 분석**: MediaPipe (Pose Landmarker / Hands Landmarker / Face Landmarker)
- **데이터 저장**: 브라우저 로컬 저장소 (IndexedDB) — 별도 백엔드 없음

## 실행 방법

```bash
npm install
npm run dev
```

## 역할 분담

| 역할 | 담당 | 내용 |
|---|---|---|
| 프론트엔드 + 엔진 통합 | sg | 전체 구조 설계, 어려운 로직(소근육 지표 등), 팀 통합 |
| 프론트엔드 | 팀원 1 | 화면 구현 (온보딩, 과제, 촬영, 결과, 기록, 진료요약) |
| 영상·지표 엔진 | 팀원 2 | MediaPipe 연동, 대근육·사회성 지표 판정 로직 |

자세한 내용은 [`docs/roles.md`](docs/roles.md) 참고.

## MVP 측정 지표

| 영역 | 지표 |
|---|---|
| 대근육운동 | 독립 서기 유지 시간 |
| 소근육운동 | 블록 쌓기 시도-성공 (또는 핀치 그립 유지 시간) |
| 사회성 | 호명 후 고개 돌림까지의 반응 지연 시간 |

엔진이 프론트에 제공하는 함수 스펙은 [`docs/interface.md`](docs/interface.md) 참고.

## 참고 — 범위에서 제외한 것

- K-DST 문항 원문은 사용하지 않음 (저작권·사용 자격 제한) — 다루는 발달 영역만 참고해 자체 과제 설계
- 언어·인지·자조 영역은 이번 MVP 범위에서 제외 (향후 확장 검토)
- "판정하지 않는다" — 발달 지연을 진단하지 않고, 관찰 가능한 지표만 제공
