# GrowthLens

영상 기반 영유아 발달 관찰 기록 및 진료 연계 웹 데모

보호자가 집에서 남긴 관찰을 정량 지표로 바꾸어, 의사의 판단 근거로 전달합니다.

## 개요

- **대상**: 14~15개월 영유아의 보호자
- **관찰 과제**: 호명반응 · 동작 모방 · 공 주고받기 (MVP 범위)
- **플랫폼**: 웹 (클라이언트 전용, 백엔드 서버 없음)
- **현재 단계**: 로컬 데모 (배포 없음)

보호자가 앱의 안내에 따라 아이의 행동(호명 반응, 동작 모방, 공 주고받기)을 촬영하면,
브라우저에서 바로 분석해 정량 지표로 보여주고 기록합니다.

과제 구성과 특징 추출은 국내 선행 연구를 따릅니다 — 국내 9개 상급종합병원 510명을 대상으로 한
[npj Digital Medicine 8:607 (2025)](https://pmc.ncbi.nlm.nih.gov/articles/PMC12514021/).
단, **우리는 분류·판정을 하지 않습니다.** 측정값과 변화만 제공합니다.

## 기술 스택

- **Frontend**: React
- **영상 분석**: MediaPipe (Pose Landmarker / Hands Landmarker / Face Landmarker)
- **데이터 저장**: 브라우저 로컬 저장소 (IndexedDB) — 별도 백엔드 없음

## MVP 측정 지표

지표를 2층으로 나눕니다.

**1군 — 공통 지표.** 과제와 무관하게 모든 영상에서 계산됩니다. 포화되지 않으므로 종단 그래프의 기본 축입니다.

| 지표 | 산출 |
|---|---|
| 보호자 지향 시간 | 아이 머리 방향이 보호자를 향한 누적 시간 |
| 활동량 | 아이 몸의 위치·자세가 변한 누적 시간 |
| 신체 접촉 시간 | 보호자 손이 아이 몸에 닿아 있던 누적 시간 (참고값) |

**2군 — 과제 지표.** 해당 과제를 수행한 영상에서만 나옵니다.

| 과제 | 지표 |
|---|---|
| 호명반응 | 호명 후 고개 돌림까지의 반응 지연 시간 |
| 동작 모방 | 보호자 시범 후 모방까지의 지연 시간 |
| 공 주고받기 | 전달 성공 여부와 전달 시간 |

언어·인지·자조는 측정하지 않고 과제 안내와 영상 보관까지만 합니다.

지표 정의와 임계값은 [`docs/engine.md`](docs/engine.md), 엔진↔프론트 계약은 [`docs/interface.md`](docs/interface.md), 화면 구성은 [`docs/screens.md`](docs/screens.md) 참고.

## 참고 — 범위에서 제외한 것

- K-DST 문항 원문은 사용하지 않음 (저작권·사용 자격 제한) — 다루는 발달 영역만 참고해 자체 과제 설계
- 언어·인지·자조 영역은 이번 MVP 범위에서 제외 (향후 확장 검토)
- "판정하지 않는다" — 발달 지연을 진단하지 않고, 관찰 가능한 지표만 제공
